## 🚀 Quick Start

### Open Any Demo
```bash
# Option 1: Direct open (macOS)
open bento-layout.html

# Option 2: Python local server
python -m http.server 8000

# Option 3: Node/NPM
npx http-server
```

Then visit: `http://localhost:8000/[filename].html`
